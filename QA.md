# QA review - 21 November 2026

## Result and scope

Reviewed the existing task dashboard and FastAPI/MySQL authentication implementation. Tested the browser behavior in Chromium, inspected desktop/mobile screenshots, and exercised the real local MySQL database with a disposable account. Each confirmed defect below has a separate fix commit and regression coverage.

Final combined run with `TASKWELL_TEST_MYSQL=1`: **75 passed**, with one third-party deprecation warning. The default run without MySQL opt-in passed **74 tests** and skipped the integration test.

## Coverage

- **Dates:** past/today/future views; completed future tasks; overdue labels; date sorting; midnight rollover; leap day; year end; impossible dates; five-digit years; maximum supported future date. Date-filter tests run in Asia/Kolkata, America/Los_Angeles, and Pacific/Kiritimati.
- **Tasks:** create/edit/complete/delete; cancel deletion; search notes without case sensitivity; summary totals and completion percentage; persistence after refresh; empty lists; account-specific storage; safe text rendering of markup.
- **Storage:** damaged data preservation; cross-tab updates; full-storage fallback and recovery. Same-task simultaneous edits remain last-save-wins; localStorage is not a transactional database.
- **Authentication:** signup and duplicate email; incorrect credentials; valid/expired/revoked sessions; logout; frontend/server validation; missing/reset tokens; fragment cleanup; email-delivery failure; generic recovery responses; rate limits; JSON/body-size/origin checks.
- **MySQL integration:** real browser signup/login/reset/logout, unique-email constraint, cascade foreign keys, session invalidation, old-password rejection, token replay, and two concurrent resets of one token. Exactly one concurrent reset succeeds.
- **Display:** all five pages checked for horizontal overflow at 320, 375, 768, and 1366 pixels. Desktop/mobile dashboard and mobile signup screenshots visually inspected. Long account names also checked at 320 pixels.
- **Repository:** JavaScript syntax, Python compilation, whitespace checks, dependency consistency, and ignored local secrets/email previews.

## Reproduce

See the test commands in [README.md](README.md). The default suite skips the MySQL test; set `TASKWELL_TEST_MYSQL=1` to include it. Browser tests use isolated contexts and a temporary HTTP server. The live MySQL check starts its own API on a temporary port and removes its uniquely named user and email previews afterward.

Screenshots are regenerated by `frontend/tests/test_visual_evidence.py` under ignored `test-results/`:

- `dashboard-desktop.png`
- `dashboard-mobile.png`
- `signup-mobile.png`

## Limits

- Browser automation covers Chromium, not Firefox, Safari, or physical mobile devices.
- Real SMTP delivery was not tested; local email previews and simulated delivery failures were tested. No messages were sent to real recipients.
- Tasks remain browser-local by project design; there is no task database/API, cross-device synchronization, or production deployment test.
- This is functional/regression QA, not a full accessibility audit, penetration test, or load test.
- The installed Starlette test client emits a dependency deprecation warning about `httpx`; it does not cause a failed test.
